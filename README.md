# Yandex Discord Presence

**Текущий трек из Яндекс Музыки — в профиле Discord.**

Небольшая утилита для десктопной Яндекс Музыки. Читает медиасессию Windows и показывает в Discord название песни, исполнителя, обложку и время воспроизведения. Файлы плеера менять не нужно, токен аккаунта тоже не нужен.

Управление — в отдельном окне: запуск и остановка, автозапуск, оформление статуса и журнал.

## Что умеет

- Показывает текущий трек с обложкой и шкалой времени.
- Добавляет кнопку **«Открыть трек»**, если найдена его страница в Яндекс Музыке.
- Оставляет песню на паузе с пометкой **«Пауза»**, без бегущего таймера.
- После пяти минут неизменной паузы убирает статус и отключает RPC. Музыка возобновилась — статус вернулся. Смена трека и перемотка сбрасывают отсчёт.
- Очищает статус при закрытии плеера и ждёт следующего запуска.
- Позволяет менять строки статуса, тип активности, обложку, таймер и кнопку.
- Запускается в фоне при входе в Windows, если включён автозапуск.

## Перед запуском

Понадобятся **Windows 10/11**, **Discord для ПК**, десктопная **Яндекс Музыка** и **Python 3.12, 64-bit**.

Установите Python со [страницы Python 3.12](https://www.python.org/downloads/release/python-31210/). В установщике оставьте включёнными **pip**, **Tcl/Tk** и **Python Launcher**. Python другой версии может не подойти для `winsdk`.

Обычный клиент и PulseSync подходят, если публикуют медиасессию Windows. Если у PulseSync уже включена интеграция с Discord, отключите её, чтобы не было двух статусов.

## Быстрый старт

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте в постоянную папку.
2. Откройте [Discord Developer Portal](https://discord.com/developers/applications) и создайте приложение. Его имя появится в заголовке активности — например, `Yandex Music`. Скопируйте **Application ID**.
3. Запустите **`control.cmd`**. На вкладке **«Подключение»** вставьте ID и нажмите **«Сохранить и применить»**.
4. Нажмите **«Запустить»**, откройте Discord и включите песню в Яндекс Музыке.

При первом запуске отсутствующие зависимости устанавливаются в `sys/.deps`; понадобится интернет. `config.json` создаётся при сохранении настроек. Вручную копировать пример необязательно.

Для запасной обложки можно загрузить изображение в **Rich Presence → Art Assets** вашего Discord-приложения и указать его имя в настройках. По умолчанию используется `yandex_music`.

## Управление

| Действие | Результат |
| --- | --- |
| Запустить | Запускает фоновую интеграцию |
| Остановить | Завершает интеграцию и убирает её статус |
| Перезапустить | Заново подключается к Discord с текущими настройками |
| Включить автозапуск | Запускает интеграцию сейчас и при следующих входах в Windows |
| Выключить автозапуск | Отключает запуск при входе; работающая интеграция продолжает работать |
| Сохранить и применить | Сохраняет настройки и перезапускает интеграцию, если она работает |

**Закрытие окна управления не останавливает интеграцию.** Для этого есть кнопка «Остановить».

На вкладке **«Вид статуса»** доступны шаблоны двух строк. Например:

```text
Первая строка: {title}
Вторая строка: {artist} · {album}
```

Подстановки: `{title}` — песня, `{artist}` — исполнитель, `{album}` — альбом. Для альбома медиасессия иногда возвращает пустую строку.

Предпросмотр помогает подобрать текст. Обложка и время в нём условные; окончательный вид карточки задаёт Discord. Поиск кнопки и обложки работает по названию и исполнителю: при неоднозначном совпадении ссылка может отсутствовать.

Немедленное скрытие на паузе настраивается отдельно. Пятиминутное отключение можно выключить на вкладке «Подключение».

## Если статус не появился

- Проверьте, что Discord для ПК запущен и разрешает показывать текущую активность.
- Проверьте Application ID: это ID приложения, а не пользователя.
- Откройте вкладку **«Журнал»** и обновите сообщения. Ошибки подключения видны там.
- Кнопка перехода к песне не отображается при просмотре **собственного** профиля — её видят другие пользователи.
- Если клиент не найден, проверьте `process_names` и `source_keywords` в `config.json`. Имена доступных медиасессий можно вывести из PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\sys\control.ps1 -Action sessions
```

Нужен другой путь к Python? Задайте переменную окружения `YANDEX_PRESENCE_PYTHON` с полным путём к `python.exe`. Рядом должен находиться `pythonw.exe`.

## Файлы проекта

```text
control.cmd          Запуск окна управления
config.example.json  Пример настроек без личного Application ID
sys/
  app.py             Интерфейс и предпросмотр
  presence.py        Медиасессия, Rich Presence и таймер паузы
  control.ps1        Управление фоновой задачей Windows
  python.ps1         Поиск Python
  launch.ps1         Запуск окна без консоли
  launch.vbs         Скрытый запуск PowerShell
  requirements.txt   Зависимости интеграции
tests/               Проверки таймера и оформления статуса
```

`config.json`, зависимости, журналы и временный статус создаются локально и исключены из Git. Служебную папку `sys` удалять не нужно.

Перед переносом проекта выключите автозапуск и остановите процесс. После переноса включите автозапуск из новой папки — задача Windows должна знать новый путь.

## Разработка

Проверки логики не требуют Discord, плеера или установки зависимостей:

```powershell
python -m unittest discover -s tests -v
```

GitHub Actions проверяет синтаксис Python, PowerShell и логику статуса на Windows. Проверки не заменяют запуск с настоящими Discord и медиасессией.

Проект не связан с Яндексом или Discord. Он использует локальный Discord RPC и медиасессии Windows; для поиска обложки и ссылки обращается к публичному поиску Яндекс Музыки.
